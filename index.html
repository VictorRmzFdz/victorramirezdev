⏰ Sistema de Recursos Humanos

Sistema de Control de Asistencia con Análisis de Descansos

Sistema avanzado de control de asistencia que procesa checadas, calcula horas laboradas, detecta retardos, analiza el cumplimiento de descansos (con ajuste automático de entradas), justifica faltas y genera reportes detallados con excedentes semanales.

  • Procesamiento de checadas (entrada/salida)
  • Cálculo de horas laboradas con ajuste de entradas
  • Análisis de descanso (duración y horario)
  • Justificación de faltas con archivo adjunto
  • + más funcionalidades
PHP 8.2 MySQL JavaScript jQuery Bootstrap
3
💰 Sistema de Producción

Módulo de Costeo de Productos en Tiempo Real

Herramienta para calcular costos de productos usando materiales, desperdicios, costos variables y márgenes. Permite seleccionar materiales, definir dimensiones y unidades, y obtener precios sugeridos para aficionado, mayoreo y especial.

  • Búsqueda y selección de materiales
  • Cálculo de piezas por material (con conversión de unidades)
  • Aplicación de desperdicios y costos variables
  • Cálculo de precios con diferentes márgenes
  • + más funcionalidades
PHP 8.2 MySQL JavaScript Ajax Bootstrap
3
🖨️ Sistema de Producción

Sistema de Gestión de Cierres de Minilab y Control de Producción

Sistema especializado para el control de producción en laboratorios fotográficos y de impresión. Permite gestionar cierres de máquinas, controlar el consumo de tintas, registrar desperdicios y calcular la eficiencia operativa de los equipos.

  • Registro de cierres de máquina con control de contadores
  • Gestión de canales de impresión por máquina
  • Control de consumo de tintas y materiales
  • Registro de desperdicios por tipo y tamaño
  • + más funcionalidades
PHP 8.2 MySQL JavaScript jQuery Bootstrap

🏢 Sistema Empresarial Completo

Sistema FaciOne - Punto de Venta e Intranet Empresarial

Sistema integral de Punto de Venta e Intranet para una empresa con 7 sucursales, 1 bodega y más de 50 colaboradores. Incluye módulos de ventas, inventario, traspasos, clientes, convenios, metas, cortes de caja y control de créditos. Desarrollado con arquitectura MVC en PHP 8.2.

  • Punto de Venta con carrito en tiempo real y múltiples métodos de pago
  • Control de inventario con traspasos entre sucursales
  • Gestión de clientes con precios especiales por convenio
